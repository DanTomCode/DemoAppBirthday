# DemoAppBirthday 🎂

Benvenuto in **DemoAppBirthday**, una semplice e intuitiva applicazione Android sviluppata in Kotlin che permette di calcolare rapidamente la propria età inserendo la data o l'anno di nascita.

## 🚀 Funzionalità

- **Calcolo dell'età in tempo reale**: Inserisci il tuo anno di nascita e premi il pulsante **Calcola** per scoprire subito quanti anni hai.
- **Interfaccia pulita e moderna**: 
  - Design edge-to-edge con barra degli strumenti pulita.
  - Testo guida in evidenza (grassetto) e centrato.
  - Campo di input numerico intuitivo.
  - Visualizzazione del risultato pulita (senza bordi o linee superflue) posizionata sopra il campo di inserimento.

## 🛠️ Tecnologie Utilizzate

- **Linguaggio**: Kotlin
- **UI**: XML Layouts (ConstraintLayout, NestedScrollView, Material Components)
- **Navigazione**: Jetpack Navigation Component
- **Compatibilità**: AndroidX, supporto Edge-to-Edge nativo
